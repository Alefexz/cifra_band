# Central de Suporte Cifra Band

Painel local para acompanhar feedbacks enviados pelo app.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Segurança

O arquivo `config.js` fica somente no computador e esta ignorado pelo Git. O painel exige login Firebase e a API so libera tickets para administradores do mesmo ministerio.
