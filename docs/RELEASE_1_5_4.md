# Cifra Band 1.5.4 (build 22)

- Registra a versao instalada por aparelho para os avisos de atualizacao.
- Quando o Render recebe uma requisicao, verifica avisos pendentes e envia push aos aparelhos Android registrados com versao antiga.
- O celular pode receber o aviso com o app fechado. Tocar nele abre o app, que consulta a versao atual e oferece o download.
- Controla envios por aparelho e build no banco para evitar repeticoes em novas aberturas ou reinicios do servidor.
- Mantem todas as correcoes de cifras, tons e setlists da 1.5.3.

Esta versao precisa ser instalada e aberta uma vez com login e internet para registrar o aparelho. As versoes anteriores nao informavam o build por token e nao podem ser classificadas com seguranca como desatualizadas. O novo fluxo vale para as atualizacoes seguintes.

Atualizacao opcional para quem ja esta na 1.5.3. Aparelhos anteriores ao build 21 continuam precisando da atualizacao corretiva.
